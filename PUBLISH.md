# Publish Daniel A. Dare's Website

## Fastest option: GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a repository named exactly `YOUR-GITHUB-USERNAME.github.io` for a personal site.
3. Upload **all files and folders** from this website package, including `.github`, `.nojekyll`, `404.html`, and `index.html`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose the GitHub Actions deployment option if prompted. The included workflow will publish the site from the `main` branch.
6. Open `https://YOUR-GITHUB-USERNAME.github.io` after deployment.

GitHub notes that a user site uses the `<username>.github.io` naming pattern and can be published from Pages settings. Changes may take a few minutes to appear.

## Custom domain

When you have a domain such as `danieladare.com`, add it through the repository's **Settings → Pages → Custom domain** area and follow GitHub's DNS instructions. Do not add a `CNAME` file until you know the exact domain you want to use.
