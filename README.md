# Daniel A. Dare Website

A responsive, self-contained static website for Daniel A. Dare, Experienced Book Marketer & Reader Discovery Strategist.

## Included

- `index.html` — complete website
- `404.html` — custom 404 page
- `.nojekyll` — static hosting helper
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Use the repository's **Settings → Pages** area to configure GitHub Pages, or use the included workflow.
4. For a user site, a repository named `<your-username>.github.io` can publish at `<your-username>.github.io`.
